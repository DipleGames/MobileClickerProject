# ⚔️ Mobile Clicker Game

Unity와 C#을 활용하여 개발한 **2D 모바일 방치형 클리커 RPG**입니다.

플레이어가 화면을 터치하여 몬스터를 공격하고, 획득한 골드로 공격력을 강화하며 더 높은 스테이지에 도전하는 게임입니다.

단순한 조작으로 성장의 재미를 느낄 수 있도록 설계했으며, 반복적인 전투와 무한 스테이지 진행을 중심으로 개발하고 있습니다.

## 🎮 주요 게임 시스템

### 1. 전투 시스템

- 화면 터치를 통한 몬스터 공격
- 공격력 및 스킬 배율을 적용한 데미지 계산
- 몬스터 피격 및 사망 처리
- Animator Override Controller를 활용한 몬스터별 애니메이션 관리

### 2. 무한 스테이지 시스템

- 스테이지 진행에 따라 몬스터 체력 및 보상 증가
- 일정 스테이지마다 보스 몬스터 등장
- StageConfig를 활용한 스테이지 성장 계수 관리
- StageDataGenerator를 통한 스테이지 데이터 동적 생성

### 3. 성장 및 업그레이드 시스템

- 골드를 소비하여 기본 공격력 강화
- 공격력 레벨에 따른 성장 계수 적용
- 업그레이드 레벨에 따른 비용 증가
- 공격력 계산과 업그레이드 구매 로직 분리

### 4. 스킬 시스템

- 스킬별 공격 배율 및 재사용 대기시간 관리
- 스킬 데이터와 실행 상태 분리
- 스킬 해금 조건 및 잠금 UI
- 스킬별 독립적인 실행 상태 관리

### 5. 데이터 저장 및 오프라인 보상

- JSON 기반 게임 데이터 저장 및 불러오기
- Application.persistentDataPath 활용
- 공격력 레벨, 골드 등 플레이어 진행 데이터 관리
- UTC 시간을 활용한 오프라인 경과 시간 계산

### 6. UI 및 연출

- 모바일 해상도를 고려한 반응형 UI
- DOTween을 활용한 데미지 및 보상 텍스트 연출
- 화면 흔들림을 통한 타격감 표현
- ScrollRect를 활용한 스킬 목록 UI
- 오브젝트 풀링을 활용한 반복 생성 UI 관리

## 🏗 주요 시스템 구조

**GameManager**

게임 초기화 및 저장 데이터 로드, 전체 게임 흐름 관리

**StageManager**

현재 스테이지 관리, 몬스터 생성 및 다음 스테이지 진행

**AttackManager**

공격력 레벨과 각종 배율을 적용한 최종 공격력 계산

**UpgradeManager**

업그레이드 비용 계산 및 골드 소비 처리

**SkillManager**

스킬 실행, 쿨타임 및 스킬 상태 관리

**SaveManager**

게임 데이터 직렬화 및 로컬 저장 처리

**PoolManager**

제네릭 오브젝트 풀을 활용한 반복 생성 객체 관리

## 💡 주요 구현 특징

### 동적 스테이지 데이터 생성

모든 스테이지의 데이터를 미리 생성하지 않고, 스테이지 번호와 성장 계수를 기반으로 몬스터 체력 및 보상을 계산하도록 설계했습니다.

이를 통해 무한 스테이지 진행에 대응하고, 성장 밸런스를 설정값으로 조정할 수 있도록 구현했습니다.

### 데이터와 실행 로직 분리

ScriptableObject를 활용하여 성장 계수 및 스킬 설정값을 관리하고, 실제 계산과 실행은 별도의 매니저 및 런타임 클래스에서 처리하도록 구성했습니다.

이를 통해 밸런스 조정 시 코드 수정 범위를 줄이고, 새로운 콘텐츠를 추가하기 쉽도록 설계했습니다.

### 오브젝트 풀링

전투 중 반복적으로 생성되는 보상 텍스트 등의 객체에 오브젝트 풀링을 적용했습니다.

객체를 매번 생성하고 제거하는 대신 재사용하여 불필요한 메모리 할당과 GC 발생을 줄이도록 구성했습니다.

### 로컬 데이터 저장

Unity의 JsonUtility를 활용하여 플레이어 진행 데이터를 JSON 형식으로 저장합니다.

마지막 저장 시간을 UTC 기준으로 기록하여 게임 재실행 시 오프라인 경과 시간을 계산할 수 있도록 구현했습니다.
